# Oni Labs Games

Public developer website for Pip’s Adventure.

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, **main**, **/(root)**, and Save.

Expected website: https://cliffman1978-source.github.io/

AdMob verification: https://cliffman1978-source.github.io/app-ads.txt

Set the website root URL in Google Play Console → Store settings → Store listing contact details → Website. Keep the existing privacy-policy URL unchanged.

After the website and app-ads.txt are publicly reachable and the Play listing change is published, ask AdMob to check for updates. AdMob verification and app readiness review are separate from publishing this website.
